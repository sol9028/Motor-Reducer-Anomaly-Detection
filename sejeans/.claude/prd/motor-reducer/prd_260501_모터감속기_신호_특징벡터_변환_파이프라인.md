# PRD: 모터 감속기 신호 데이터 특징 벡터 변환 파이프라인

> 7조 | 박세진(C321027) · 박솔 | 홍익대 시스템분석/설계

---

## 1. 이전 단계의 문제점

기존 모터 감속기 결함 진단 파이프라인에서 스펙트로그램 PNG(1280×2000)를 그대로 모델에 입력하면 다음 문제가 발생한다.

- **과도한 입력 차원**: 원본 픽셀 수 2,560,000개 → 경량 모델(SVM, Random Forest) 입력 불가.
- **결함 신호 희석**: 결함은 짧은 순간에만 나타나므로 시간 축 평균 집계 시 노이즈에 묻힌다.
- **도메인 지식 미반영**: 편심 결함 관련 1.2~1.8 kHz 대역 에너지 등 물리적 특성이 단순 픽셀 특징에 반영되지 않는다.
- **해석 불가**: 픽셀을 그대로 입력하면 모델이 어떤 주파수 패턴을 근거로 판단하는지 추적할 수 없다.
- **라벨 정보 미활용(v1.0 추가)**: 전문가가 결함 영역을 polygon으로 표시한 라벨 데이터가 있으나, 이 공간 정보가 특징 추출에 전혀 반영되지 않는다.

---

## 2. 해결 방법

### 2-1. 기본 전략

PNG 스펙트로그램에서 **도메인 지식 기반 수작업 특징 추출(handcrafted feature extraction)** 파이프라인을 구성한다.  
v2.0에서는 여기에 **polygon 라벨 기반 결함 주파수 대역 특징(9차원)** 을 추가하여 최종 **76차원 특징 벡터**를 생성한다.

---

### 2-2. Polygon 라벨 데이터 분석

#### JSON 구조

각 PNG 이미지에 대응하는 JSON 파일은 다음 필드를 갖는다.

```json
{
  "category": { "id": 3, "name": "DEMAG" },
  "image": { "width": 2000, "height": 1280, "sensor_name": "Current_U" },
  "annotations": {
    "polygons": [[[x0, y0], [x1, y1], ..., [x0, y0]]]
  },
  "metadata": { "speed": 2902.89 }
}
```

- 좌표계: `x` = 시간 축 (0 ~ 2000 픽셀), `y` = 주파수 축 (0 = 이미지 상단, 1279 = 이미지 하단)
- NumPy 배열 기준: `arr[y, x]`로 접근

#### 결함 유형별 Polygon 분석 결과

| 결함 유형 | polygon y 최솟값 | polygon y 최댓값 | 시간 축 범위 | 비고 |
|---|---|---|---|---|
| DEMAG | ~723 | ~1098 | 0 ~ 2000 (전체) | 주파수 대역 집중형 |
| ECC10 | ~791 | ~1017 | 0 ~ 2000 (전체) | 주파수 대역 집중형 |
| ECC20 | ~726 | ~1006 | 0 ~ 2000 (전체) | 주파수 대역 집중형 |
| REDUC | (비어 있음) | (비어 있음) | — | 국소 결함 영역 없음 |
| NORMAL | (해당 없음) | (해당 없음) | — | 정상 클래스 |

**핵심 관찰**:
1. polygon은 시간 축을 거의 전부 포함하며, **y(주파수) 축의 특정 범위만 한정**한다.
2. polygon이 실질적으로 전달하는 정보는 **"결함 신호가 집중된 주파수 대역"** 이다.
3. REDUC는 감속기 기어 결함으로 주파수 특성이 분산되어 있어 polygon이 비어 있다.

#### Polygon 좌표 → 주파수 대역 해석

이미지 좌표계에서 `y=0`이 이미지 상단(고주파)이므로, polygon의 y 범위는 다음과 같이 해석된다.

```
y_min (상단) → 고주파 경계
y_max (하단) → 저주파 경계
freq_centroid = 에너지 가중 평균(y 좌표)
```

실제 주파수 값은 PNG 생성 시의 STFT 파라미터(샘플링 레이트, window size)에 따라 결정되나, 본 파이프라인에서는 픽셀 row 인덱스를 주파수 프록시(proxy)로 사용한다.

---

### 2-3. Polygon 특징의 훈련/추론 적용 전략

SVM·Random Forest는 훈련과 추론에서 동일한 차원의 특징 벡터가 필요하다. Polygon은 훈련 데이터에만 존재하므로 다음 전략을 사용한다.

```
[훈련 단계]
  ① 각 샘플의 JSON에서 polygon 파싱
  ② polygon mask 생성 → ROI 에너지 통계 계산
  ③ polygon이 없는 샘플(REDUC/NORMAL) → fallback 처리

[추론 단계]
  ① 훈련 데이터에서 계산한 결함 대역 통계를 고정 파라미터로 저장
     fault_zone = (y_min=723, y_max=1098)  ← 모든 결함 클래스의 polygon union
  ② 이 고정 대역을 적용하여 동일 9개 특징을 계산
  ③ 특징 벡터 형상 (76,) 유지
```

---

### 2-4. 전체 파이프라인

```
PNG 스펙트로그램 이미지 로드 + JSON polygon 파일 로드
(PNG: 1280 × 2000, 그레이스케일 | JSON: polygon 좌표 리스트)
        ↓
[1단계] 이미지 → NumPy 배열 변환
        shape: (H=1280, W=2000) | 행=주파수 bin, 열=시간 프레임
        ↓
[2단계] Polygon 파싱 및 결함 주파수 대역 추출
        JSON에서 polygon 좌표 추출
        - polygon 있음: y_min, y_max, mask 생성
        - polygon 없음(REDUC/추론): 고정 fault_zone 또는 전체 대역 사용
        ↓
[3단계] 주파수 프로파일 생성
        arr.max(axis=1) → shape (1280,)
        ※ Max 사용: 결함 신호는 순간적이므로 평균은 노이즈에 묻힘
        ↓
[4단계] 주파수 대역별 에너지 (Band Energy)
        1280 bin → 16대역 균등 분할 (80 bins/대역)
        band_energy     (16차원): 대역별 평균 에너지
        band_energy_std (16차원): 대역별 에너지 표준편차
        ↓
[5단계] 주파수 피크 탐지
        scipy.signal.find_peaks(prominence=10, distance=20)
        → Top-10 피크 선택 (prominence 기준)
        peak_freqs       (10차원): 피크 주파수 bin 위치
        peak_heights     (10차원): 피크 에너지 높이
        peak_prominences (10차원): 피크 돌출 정도
        ↓
[6단계] 전체 통계량
        mean, std, max, 95th percentile, 99th percentile → (5차원)
        ↓
[7단계] Polygon ROI 특징 추출 ← NEW
        polygon mask(또는 고정 fault_zone)를 적용하여
        결함 주파수 대역 내 에너지 통계 계산 → (9차원)
        ↓
[8단계] 특징 벡터 조합
        np.concatenate([
            band_energy(16), band_energy_std(16),
            peak_freqs(10), peak_heights(10), peak_prominences(10),
            stats(5),
            poly_features(9)           ← NEW
        ])
        → shape (76,)
        ↓
SVM / Random Forest 분류 모델 입력
```

### 2-5-2. Polygon ROI 특징 상세 설명

> **공통 전제**
> - `arr`: shape (1280, 2000)의 NumPy 배열 (픽셀값 = 에너지 크기, 0~255)
> - `mask`: polygon 영역을 나타내는 boolean 배열 (1280, 2000) — True = 결함 대역 내부
> - `y_min`, `y_max`: polygon 꼭짓점 y 좌표의 최솟값·최댓값 (이미지 상단 = 0)
> - polygon이 없거나 추론 모드: mask = 고정 fault_zone 또는 전체 대역으로 대체

---

#### ① poly_roi_mean — 결함 대역 평균 에너지

**계산 공식**
```python
roi_pixels = arr[mask]          # polygon 내부 픽셀 전체를 1D 배열로 추출
poly_roi_mean = np.mean(roi_pixels)
```

**물리적 의미**  
결함 주파수 대역에 축적된 평균 에너지 수준이다. 결함이 발생하면 해당 주파수 대역에 에너지가 집중되므로 정상 상태보다 높은 값이 나타난다. ECC·DEMAG처럼 결함 대역이 명확한 클래스에서 가장 변별력이 강하다.

**구현 유의사항**
- mask가 전체 이미지를 덮는 경우(REDUC fallback): `roi_pixels = arr.ravel()`과 동일하므로 global_mean과 같아진다.
- 이미지가 그레이스케일 0~255가 아닌 float dB 스케일인 경우에도 동일 공식이 적용된다.

**결함 유형별 예상 동작**

| 클래스 | 예상 값 | 이유 |
|---|---|---|
| DEMAG | 높음 | 감자 결함으로 해당 대역 에너지 집중 |
| ECC10 / ECC20 | 높음 | 편심으로 인한 사이드밴드 에너지 집중 |
| REDUC | 전체 평균 수준 | polygon 없음 → 전체 대역 mean과 동일 |
| NORMAL | 낮음 | 결함 대역에 에너지 집중 없음 |

---

#### ② poly_roi_std — 결함 대역 에너지 시간 변동성

**계산 공식**
```python
poly_roi_std = np.std(roi_pixels)
```

**물리적 의미**  
polygon 내부 픽셀 강도의 표준편차다. 결함 신호는 회전체의 주기적 특성 때문에 시간 축 방향으로 강도가 반복적으로 변동한다. 이 변동성이 크다는 것은 결함 에너지가 특정 시간 구간에 집중적으로 나타남을 의미한다.

**구현 유의사항**
- std는 픽셀 수가 많을수록 안정적이다. polygon 면적이 너무 작으면 노이즈 민감도가 올라가므로 픽셀 수를 사전에 검증한다.

**결함 유형별 예상 동작**

| 클래스 | 예상 값 | 이유 |
|---|---|---|
| ECC10 / ECC20 | 높음 | 회전 주기와 동기화된 에너지 버스트가 시간 축에 반복 |
| DEMAG | 중간 | 에너지 집중은 있으나 ECC보다 시간 변동 폭이 작음 |
| REDUC | 낮음~중간 | 전체 대역 사용 → 변동성이 희석됨 |
| NORMAL | 낮음 | 배경 노이즈 수준의 균일한 분포 |

---

#### ③ poly_roi_max — 결함 신호 피크 강도

**계산 공식**
```python
poly_roi_max = np.max(roi_pixels)
```

**물리적 의미**  
결함 대역에서 관측된 최대 에너지값이다. 결함 심각도(severity)의 직접 지표로, 결함이 심할수록 순간 피크 에너지가 커진다. ECC20은 ECC10보다 편심량이 크므로 이 값이 더 높을 것으로 예상된다.

**구현 유의사항**
- 이미지 압축 아티팩트나 단일 노이즈 픽셀에 의해 과대 추정될 수 있다. `poly_roi_p95`와 함께 사용하여 상호 보완한다.

**결함 유형별 예상 동작**

| 클래스 | 예상 값 | 이유 |
|---|---|---|
| ECC20 | 가장 높음 | ECC10보다 편심량이 커 에너지 피크가 더 강함 |
| DEMAG | 높음 | 감자 결함 영역 에너지 집중 |
| ECC10 | 중간~높음 | ECC20보다 경미한 편심 |
| REDUC / NORMAL | 낮음 | 결함 집중 대역 없음 |

---

#### ④ poly_roi_p95 — 결함 피크의 안정적 상한 추정

**계산 공식**
```python
poly_roi_p95 = np.percentile(roi_pixels, 95)
```

**물리적 의미**  
polygon 내부 픽셀 중 상위 5%를 제외한 최대값이다. `poly_roi_max`가 단일 이상 픽셀에 민감한 데 반해, p95는 노이즈·아티팩트에 강건한 피크 에너지 추정치를 제공한다. 임계값 기반 심각도 판단에 더 신뢰할 수 있는 지표다.

**구현 유의사항**
- `roi_pixels`가 빈 배열이면 `np.percentile`이 오류를 낸다. fallback mask를 항상 비어 있지 않게 보장해야 한다.
- poly_roi_max와 p95의 차이가 크면 이미지에 국소 노이즈가 있다는 신호다.

---

#### ⑤ poly_vs_bg_ratio — 결함 대역 대 배경 에너지 대비비

**계산 공식**
```python
roi_pixels = arr[mask]
bg_pixels  = arr[~mask]

if bg_pixels.size == 0:          # mask가 전체 이미지를 덮는 경우 (REDUC)
    poly_vs_bg_ratio = 1.0
else:
    poly_vs_bg_ratio = np.mean(roi_pixels) / (np.mean(bg_pixels) + 1e-8)
```

**물리적 의미**  
결함 대역의 평균 에너지를 비결함 대역(배경) 평균 에너지로 나눈 값이다. 이 비율이 크면 결함 신호가 배경 노이즈 대비 명확하게 돌출되어 있음을 의미한다. SNR(Signal-to-Noise Ratio) 개념의 공간적 버전이다.

**구현 유의사항**
- `+1e-8`: 배경이 완전히 0인 경우를 방지하는 수치 안정화 항이다.
- REDUC처럼 mask가 전체 이미지인 경우 bg_pixels가 빈 배열이 되므로 반드시 분기 처리한다.

**결함 유형별 예상 동작**

| 클래스 | 예상 값 범위 | 이유 |
|---|---|---|
| DEMAG | > 1.5 | 결함 대역 에너지가 배경보다 뚜렷하게 높음 |
| ECC10 / ECC20 | > 1.3 | 사이드밴드가 배경 위로 돌출 |
| REDUC | 1.0 (고정) | 전체 대역 사용 → 분모·분자 동일 집합 |
| NORMAL | ≈ 1.0 | 고정 fault_zone 내 에너지 = 배경과 유사 |

#### ⑥ poly_freq_centroid — 결함의 지배 주파수 위치

**계산 공식**
```python
# polygon bounding box 내 주파수 프로파일 생성
zone_profile = arr[y_min:y_max, :].max(axis=1)   # shape: (y_max - y_min,)
row_indices  = np.arange(y_min, y_max)             # 픽셀 row 인덱스

total_energy = zone_profile.sum() + 1e-8
poly_freq_centroid = np.dot(row_indices, zone_profile) / total_energy
```

**물리적 의미**  
결함 주파수 대역 내에서 에너지가 가장 집중된 주파수 bin의 무게중심이다(픽셀 row 단위). 결함 유형마다 지배 주파수가 다르기 때문에 이 값이 클래스 간 구별에 기여한다.

- DEMAG: 감자 결함은 기본파의 2배 주파수 근처에 에너지 집중 → centroid 위치가 결함 특유값
- ECC10 vs ECC20: 편심량 차이가 주파수 특성 차이를 만들어 centroid가 달라질 수 있음

**구현 유의사항**
- 실제 주파수(Hz)로 변환하려면 STFT 파라미터(샘플링 레이트, window size)가 필요하다. 본 파이프라인에서는 픽셀 row를 프록시로 사용한다.
- `arr.max(axis=1)` 대신 `arr.mean(axis=1)`을 사용하면 순간 결함 신호가 희석될 수 있으므로 max를 권장한다.

**결함 유형별 예상 동작**

| 클래스 | 예상 centroid (px) | 비고 |
|---|---|---|
| DEMAG | ~900 | polygon y 범위 (723~1098)의 에너지 가중 중심 |
| ECC10 | ~900 | polygon y 범위 (791~1017)의 에너지 가중 중심 |
| ECC20 | ~860 | polygon y 범위 (726~1006)의 에너지 가중 중심 |
| REDUC | ~640 | 전체 대역(0~1280) 사용 → 전체 스펙트럼 무게중심 |
| NORMAL | 다양 | 고정 fault_zone 내 노이즈 중심 |

#### ⑦ poly_bandwidth_px — 결함 신호의 주파수 폭

**계산 공식**
```python
y_coords = [v[1] for v in polygon_vertices]   # polygon 꼭짓점의 y값 목록
poly_bandwidth_px = max(y_coords) - min(y_coords)

# fallback (polygon 없음, REDUC): 전체 스펙트럼 폭
poly_bandwidth_px = H  # = 1280
```

**물리적 의미**  
polygon이 차지하는 주파수 축 범위(픽셀 단위)다. 결함 종류마다 발생하는 하모닉 계열의 간격이 달라서 결함 신호가 포함된 주파수 폭이 다르게 나타난다.

- 폭이 넓다 → 여러 하모닉 성분이 넓게 분포 (복합 결함 또는 심각한 결함)
- 폭이 좁다 → 특정 주파수 성분에만 에너지 집중 (초기 단순 결함)

**구현 유의사항**
- polygon 꼭짓점 좌표에서 직접 계산하므로 mask 생성 없이 계산 가능하다.
- 이미 계산된 `y_min`, `y_max`를 재사용하면 중복 계산이 없다.

**결함 유형별 예상 동작**

| 클래스 | 예상 폭 (px) | 이유 |
|---|---|---|
| DEMAG | ~375 | 가장 넓은 범위 (723~1098) |
| ECC20 | ~280 | ECC10보다 심각 → 더 넓은 주파수 영향 |
| ECC10 | ~226 | 초기 편심 → 좁은 대역 |
| REDUC | 1280 | 전체 대역 fallback |
| NORMAL | (해당 없음) | 고정 fault_zone 기준 375 px |

#### ⑧ poly_peak_count — 결함 대역 내 하모닉 성분 수

**계산 공식**
```python
zone_profile = arr[y_min:y_max, :].max(axis=1)

peaks, _ = scipy.signal.find_peaks(
    zone_profile,
    prominence=5,    # 전체 스펙트럼 탐지(prominence=10)보다 낮게 설정
    distance=10      # 좁은 zone에서 인접 피크를 분리하기 위해 작게 설정
)
poly_peak_count = len(peaks)
```

**물리적 의미**  
결함 주파수 대역 내에서 에너지 프로파일이 뾰족하게 솟아오른 지점의 수다. 결함이 만드는 하모닉(배음) 성분의 개수를 반영한다.

- ECC 결함은 기본 편심 주파수와 그 배수(2×, 3×, …)에 여러 사이드밴드를 만들어 피크 수가 많다.
- DEMAG는 상대적으로 하모닉 구조가 단순하여 피크 수가 적을 수 있다.
- REDUC는 감속기 기어 치합 주파수(GMF)와 그 배수에 피크가 나타나지만 polygon 없이 전체 대역을 보므로 피크 수 의미가 희석된다.

**구현 유의사항**
- `prominence`와 `distance` 파라미터를 전체 스펙트럼 탐지보다 작게 설정한다. zone이 좁을수록 피크 구조도 세밀해지기 때문이다.
- `poly_peak_count`가 0이 나오면 zone 내에 뚜렷한 결함 성분이 없다는 신호다 (NORMAL 가능성).

**결함 유형별 예상 동작**

| 클래스 | 예상 피크 수 | 이유 |
|---|---|---|
| ECC10 / ECC20 | 높음 (3~8) | 사이드밴드 계열이 zone 내에 여러 개 |
| DEMAG | 중간 (2~5) | 2× 주파수 중심 하모닉 |
| REDUC | 중간 (전체 기준) | 기어 치합 주파수 피크 |
| NORMAL | 낮음 (0~2) | 결함 유발 하모닉 없음 |

#### ⑨ poly_area_ratio — 결함 표시 영역 비율 (REDUC 식별자)

**계산 공식**
```python
# 방법 A: mask 픽셀 카운팅 (구현 단순)
poly_area_ratio = np.sum(mask) / (H * W)

# 방법 B: Shoelace 공식 (정확한 polygon 면적)
def shoelace_area(vertices):
    n = len(vertices)
    area = 0.0
    for i in range(n):
        j = (i + 1) % n
        area += vertices[i][0] * vertices[j][1]
        area -= vertices[j][0] * vertices[i][1]
    return abs(area) / 2.0

poly_area_ratio = shoelace_area(polygon_vertices) / (H * W)

# fallback (polygon 비어 있음 또는 추론 모드):
poly_area_ratio = 0.0
```

**물리적 의미**  
전체 이미지 면적(1280 × 2000 = 2,560,000 픽셀) 대비 결함 라벨이 표시된 polygon 면적의 비율이다. 이 특징은 단독으로 **REDUC 클래스를 구별하는 핵심 식별자** 역할을 한다.

- DEMAG/ECC: polygon이 특정 주파수 대역을 가로질러 그려져 있으므로 면적비가 0보다 크다.
- REDUC: polygon이 비어 있으므로 항상 `0.0`이다.
- NORMAL: JSON 자체가 없는 경우가 많으므로 fallback으로 `0.0`이 된다.

**구현 유의사항**
- 방법 A(픽셀 카운팅)는 `PIL.ImageDraw.polygon()`으로 mask를 그린 후 `np.sum(mask)`로 구한다. 구현이 단순하고 비정형 polygon에도 정확하다.
- 방법 B(Shoelace)는 mask 생성 없이 꼭짓점 좌표만으로 계산하므로 더 빠르다. 단, 볼록하지 않은(non-convex) polygon에도 동작한다.
- 추론 모드에서 `poly_area_ratio`는 항상 `0.0`으로 고정 → 훈련 시 polygon이 있는 샘플과 다른 분포를 가진다. 모델이 이 패턴을 학습하도록 훈련 데이터에 REDUC 샘플을 충분히 포함해야 한다.

**결함 유형별 예상 동작**

| 클래스 | 예상 면적비 | 이유 |
|---|---|---|
| DEMAG | ~0.29 | 대역 폭 375px × 전체 폭 2000px / 전체 면적 |
| ECC20 | ~0.22 | 대역 폭 280px 기준 |
| ECC10 | ~0.18 | 대역 폭 226px 기준 |
| REDUC | **0.0** | 빈 polygon → REDUC 클래스 핵심 식별자 |
| NORMAL (추론) | **0.0** | JSON 없음 → fallback 0.0 |

> REDUC와 NORMAL은 `poly_area_ratio=0.0`으로 동일하지만, `poly_vs_bg_ratio`, `poly_freq_centroid`, `poly_bandwidth_px` 등 다른 특징이 두 클래스를 구별한다.

### 2-6. Polygon 없는 경우의 Fallback 처리

| 상황 | 처리 방법 | poly_area_ratio |
|---|---|---|
| 훈련 데이터, polygon 존재 | 실제 polygon mask 사용 | polygon_area / img_area |
| REDUC 훈련 샘플 (polygon 없음) | fault_zone=(0, 1280) 전체 대역 사용 | 0.0 |

```

          - mean, std, max, p95, p99 → (5,)

          - poly_area_ratio (polygon 없음 → 0.0)
          → (9,)

        ↓ FeatureVectorAssembler
          - np.concatenate → (76,)
          - shape 단언 검사

76차원 numpy 특징 벡터 → SVM / Random Forest
```

| FR-13 | 추론 모드에서는 config.json의 fault_zone_y=(723, 1098)을 고정 mask로 사용한다 | 권장 |
