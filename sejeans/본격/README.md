# 본격 — 모터-감속기 이상탐지 파이프라인

## 현행 파이프라인 (루트)

실행 순서대로:

| 파일 | 역할 |
|---|---|
| `모터_특징추출_v2.py` | 스펙트로그램 PNG → 시계열 특징 Parquet 추출. `ENABLE_ORD`, `REF_RPM`, `to_order_axis` (차수축) 포함 |
| `추출결과_검증.py` | 추출 결과 검증 → `추출결과_검증리포트.txt` 생성 |
| `모터_학습_v3.py` | 학습 (early fusion). 옵션: `--temp`, `--ext`, `--drop`, `--group-by`, `--ord`, `--no-rpm`, `--per-sensor`, `--limit` |

```
python 모터_특징추출_v2.py
python 추출결과_검증.py
python 모터_학습_v3.py --data "...\특징데이터" --out "...\모델"
```

리허설은 `--limit` 으로: `python 모터_특징추출_v2.py --limit 200`

상세 실행 가이드: `발표자료/학습_2-3단계_실행가이드.md`

## 실험/

DEMAG↔NORMAL 오분류 해결을 위한 단계별 검증 스크립트와 결과 (2026-07-30 ~ 08-08).
각 단계는 `N단계_*.py` (실행) 과 `N단계_*결과.txt` (출력) 쌍으로 되어 있다.

| 단계 | 내용 |
|---|---|
| 방안1 | LUT 역변환 효과 검증 |
| 1단계 | 컬러맵 정체 판정 (jet 여부) |
| 2단계 | 적응 임계 검증 |
| 3단계 | 차수 정규화 검증 |
| 4단계 | 방안2 확장특징 검증 |
| 5단계 | 차수 정규화 재검증 |

`LUT복원_시각화.py` 와 `시각화/` 는 위 검증 과정의 시각화 산출물이다.

> 5단계 결론: 최종 판단은 본데이터 학습(`모터_학습_v3.py`)으로 해야 한다.
