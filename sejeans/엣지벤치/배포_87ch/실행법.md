# 87채널 모델 추론속도 측정 — 실행법

MiniRocket + LogisticRegression 모델의 **청크 1개당 추론 지연시간**을 잽니다.
커널 수만 다른 87채널 모델 4개를 비교합니다.

| 파일 | 채널 | 커널 | macro-F1 |
|---|---|---|---|
| `model_registry_fuse_rpm_ext_ord_k1250.joblib` | 87 | 1,176 | 0.959 |
| `model_registry_fuse_rpm_ext_ord_k2500.joblib` | 87 | 2,436 | 0.969 |
| `model_registry_fuse_rpm_ext_ord_k5000.joblib` | 87 | 4,956 | 0.971 |
| `model_registry_ord_B_87ch_k10000.joblib` | 87 | 9,996 | 0.973 |

측정 데이터는 필요 없습니다. MiniRocket 의 연산량은 입력 **값**과 무관해서
(고정 길이 컨볼루션 + PPV 카운트) 난수 입력으로 재도 지연시간이 같습니다.
스크립트가 알아서 만듭니다.

---

## 준비 (한 번만)

Python **3.10 ~ 3.12** 가 필요합니다. `python --version` 으로 확인하세요.

### 윈도우 (PowerShell)

```powershell
cd <이 폴더>
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

`Activate.ps1` 이 실행 정책 때문에 막히면:
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` 를 먼저 한 줄 치세요.

### 리눅스 / 맥 / 라즈베리파이

```bash
cd <이 폴더>
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

라즈베리파이면 **64비트 OS 여야 합니다** (`uname -m` 이 `aarch64`).
32비트(`armv7l`)는 numba 휠이 없어서 설치가 안 됩니다.

## 실행

```
python bench_latency.py --models ./models --threads 1 --batch 1 --reps 30 --out result_t1.json
python bench_latency.py --models ./models --threads 4 --batch 1 --reps 30 --out result_t4.json
```

몇 분 걸립니다. 처음에 수십 초 멈춘 것처럼 보이는 건 numba JIT 컴파일이라 정상입니다.

여유 있으면 배치도 재주세요 (처리량 확인용):

```
python bench_latency.py --models ./models --threads 4 --batch 8 --reps 10 --out result_t4_b8.json
```

**보내주실 것**: 생성된 `result_*.json` 파일들 + 콘솔에 찍힌 마크다운 표.
그리고 **CPU 모델명**(윈도우: 작업관리자 > 성능 > CPU)도 같이요 —
어떤 하드웨어에서 잰 숫자인지 알아야 비교가 됩니다.

## 참고: 다른 PC 기준선

### numpy 를 직접 고정했다가 깨진 경우

`pip install "numpy==1.26.4"` 같은 걸 실행했다면 이렇게 됩니다:

```
scipy 1.18.1 requires numpy<2.8,>=2.0.0, but you have numpy 1.26.4
UserWarning: A NumPy version >=2.0.0 and <2.8.0 is required for this version of SciPy
ModuleNotFoundError / sklearn import 실패
```

Python 3.13 에는 numpy 1.26.4 의 cp313 휠이 없어 소스 빌드로 넘어가고, 빌드가
성공해도 scipy 와 ABI 가 안 맞습니다. **numpy 는 pip 이 고르게 두세요.**

복구:

```bash
pip install --force-reinstall "numpy>=2.0,<2.5"
python3 -c "import numpy, scipy, sklearn, sktime; print(numpy.__version__, sklearn.__version__, sktime.__version__)"
```

`2.4.x 1.7.2 1.1.0` 이 나오면 정상입니다.
