# 결론 ㅁㅈㅎ

**판정은 깔끔해: temp 기각, A4 기준선은 15채널.**

A1(15ch)과 나란히 놓으면:

| 차종 | macro-F1 (A1→A3) | DEMAG recall (A1→A3) |
| --- | --- | --- |
| IONIQ | 0.888 → 0.883 (−0.005) | 0.813 → 0.798 (−1.5%p) |
| KONA | 0.884 → 0.867 (−0.017) | 0.759 → 0.739 (−2.0%p) |
| NIRO | 0.872 → 0.869 (−0.003) | 0.770 → 0.766 (−0.4%p) |

**세 차종 전부, 두 지표 전부 하락.** 폭은 작지만 방향이 일관돼 — 한 차종만 떨어졌으면 노이즈로 볼 여지가 있는데, 3×2 전부 같은 방향이면 "temp가 도움이 안 된다"는 신호로 읽는 게 맞아.

**왜 지름길도 아닌데 떨어졌나.** temp단독 F1 0.21~0.28로 컨닝은 아니야(A2의 "안전" 판정과 일치). 그럼 남는 설명은 단순해 — **정보는 거의 없는데 채널만 3개 차지한 것.** temp는 청크(2000행) 안에서 사실상 상수라 MiniRocket이 읽을 "패턴"이 없고, 커널들이 빈 채널에 분산되면서 유효 특징의 밀도만 희석시킨 거야. rpm은 가속 곡선이라는 시계열 패턴이 있었지만 temp는 그게 없었던 게 둘의 운명을 가른 차이.

**판정 문장으로 쓰면**: "temperature는 지름길 위험은 없었으나(단독 F1 0.21~0.28) 전 차종에서 성능을 일관되게 소폭 하락시켜 기각. 채널 3개 절감으로 경량화 목표에도 부합" — 성능과 경량화가 같은 방향을 가리키는, 고민할 게 없는 기각이야. 발표에서 "온도는 왜 안 썼나" 질문의 방어 자료도 이걸로 확보됐고.

**부수 확인 2개**: 진단 1에서 timestamp 기준 클래스당 그룹 수 최소 48 — 검증 리포트 때 예상대로 통과라, 이후 모든 판정의 신뢰 기반이 재확인됐어. 그리고 A2에서 걸어뒀던 REDUC 온도 편향도 temp단독 F1이 낮게 나오면서 "실측상 문제 없음"으로 닫혔어.

**Claude Code한테 답할 내용**: "temp 기각. A4는 15ch(fuse_rpm) 기준선으로 확장특징 12개 추가해서 진행" — 이러면 A4가 45채널(15특징×3센서)로 돌 거고, 관전 포인트는 변함없이 **DEMAG recall 0.76~0.81 정체를 재분배 특징이 깨는지**야.
