# 주제에 대한 의문점

# 기존 모터-감속기, 배터리 이상 탐지 방법(현대차)

## 탐지 방법

- 현재 배터리/모터-감속기 이상 탐지의 경우 테스트 주행에서 감지한 정상 RANGE를 넘는 수치가 센서에 찍혔을 때, 배터리 퓨즈가 터지면서 셀을 지키게 되는데 (전선 차단) 이 경우 차는 퍼지게 됨.

## 문제점

- False positive 현상이 일어나서 센서데이터는 오버됐지만 실제로는 그렇지 아니하더라도 퓨즈는 터지게되며 이럴 경우 실제 문제는 일어나지 않았지만 차는 퍼지게 된다.
- 현재 위의 문제는 많이 일어나지 않지만 (축적된 데이터가 매우 방대하여 이미 ai를 사용하지 않고 인간이 라벨링한 reasonable한 데이터가 확보되어있음) 로직 에러로 인하여 (예를 들어, 전기차 시동을 걸 때, acc mode에서 시동을 키는 것과 off mode에서 시동을 키는 것 두 가지 상황에서 서로 다른 전압이 셀에 가해지게 되고 이 경우 센서 데이터가 튀어 false positive를 일으켜 퓨즈가 터지는 상황이 일어날 수도 있고, 다른 하드웨어에서 error가 발생하여 에러코드가 ECU에 전달되어 소프트웨어적으로 진행할 수가 없을 때, 퓨즈가 터지는 경우가 발생하기도 함.
    - 위의 경우 비유를 하자면, 파이썬의 경우 terminal error/kernel error/type error같은 문제가 발생하였을 때 프로그램이 멈추는 (예외 처리를 하지 않아서 발생하는 문제들을 말함) 경우 먹통이 되는 것처럼 퓨즈가 터지게 된다는 이야기이다.
