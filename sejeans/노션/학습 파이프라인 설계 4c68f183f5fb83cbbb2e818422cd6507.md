# 학교 GPU에서 학습시키는 방법

## 방법 1: 서브셋으로 학습

전체 606GB를 다 쓰지 않고 **필요한 만큼만 복사**합니다.

예를 들어 모터감속기만 먼저 한다면 Training 원천데이터 중 모터감속기 폴더만 복사. 또는 전체의 30~50%만 랜덤 샘플링해서 복사. 클래스 비율만 유지하면 학습 성능은 크게 안 떨어져요.

이렇게 하면 100~200GB 정도로 줄일 수 있어요. 대부분의 서버 로컬 디스크에 들어갑니다.

## 방법 2: 외장하드에서 직접 학습

서버에 외장하드를 꽂고 그 경로에서 바로 읽는 방법입니다. 속도는 로컬 SSD보다 느리지만 불가능한 건 아니에요. DataLoader의 num_workers를 높여서 미리 읽기(prefetch)를 최대한 활용하면 어느 정도 보완 가능합니다.

주의할 점은 USB 케이블이 빠지거나 외장하드가 절전 모드에 들어가면 학습이 죽는다는 거예요.

## 방법 3: 단계별 학습

전체를 한 번에 안 올리고 **나눠서 학습**합니다.

```
1단계: 모터감속기 데이터만 복사 → 학습 → 완료 → 삭제
2단계: 배터리 데이터만 복사 → 학습 → 완료 → 삭제
```

어차피 모터감속기 모델과 배터리 모델은 별개이니까, 동시에 디스크에 있을 필요가 없어요. 한쪽 학습 끝나면 지우고 다음 데이터 복사하면 됩니다.

## 방법 4: 네트워크 스토리지 (NAS)

학교에 공용 NAS나 네트워크 드라이브가 있으면 거기에 데이터를 올리고 서버에서 마운트해서 읽는 방법이에요. 로컬 SSD보다는 느리지만 외장하드보다는 안정적입니다. 학교 전산실에 물어보면 알 수 있어요.

## 방법 5: 라벨만 로컬, 원천은 외장

라벨 데이터는 500MB밖에 안 되니까 무조건 로컬에 넣고, 용량이 큰 원천데이터만 외장하드에서 읽는 하이브리드 방식. 라벨 읽기는 매 배치마다 일어나니까 빨라야 하고, 원천데이터는 순차적으로 읽으니까 외장하드 속도로도 감당 가능합니다.

## 추천 순서

| 우선순위 | 방법 | 조건 |
| --- | --- | --- |
| 1순위 | 단계별 학습 | 로컬에 300GB 정도만 있어도 가능 |
| 2순위 | 서브셋 학습 | 로컬에 100~200GB만 있어도 가능 |
| 3순위 | 라벨 로컬 + 원천 외장 | 로컬 여유 거의 없을 때 |
| 4순위 | 전부 외장하드 | 최후의 수단, 느리지만 동작함 |
