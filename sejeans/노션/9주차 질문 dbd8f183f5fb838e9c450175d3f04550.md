# 교수님말씀 정리

## 1. 문제 인식

- 스펙트로그램 데이터에 RGB까지 곱하면 데이터 용량이 매우 큼
- 해상도가 높아서 그대로 사용하기 어려움

## 2. 핵심 제안: 이미지 → 시계열 변환

**전체 이미지를 다 쓸 필요 없이, 핵심 특징만 추출하자**

추출할 특징:

- **시간축**: 인덱스로 사용
- **피크 주파수(Peak Frequency)**: 시간에 따라 흔들리는 중심 주파수 값
- **밴드 레인지(Band Range)**: 임계치를 넘는 영역의 시작점과 끝점 (Start ~ End)

→ 결과적으로 **3개 컬럼** 정도의 시계열 데이터로 압축 가능 (레인지를 통으로 묶으면 더 축소 가능)

## 3. 임계치 기반 필터링

- 일정 수준(임계치)을 넘는 진한 색 영역만 의미 있음
- 레인지가 작은 것들(임계치 미달)은 큰 영향 없으므로 제외
- 예: 빨갛게/주황색으로 보이는 영역의 시작과 끝만 추출

## 4. 변환 방법론

- 스펙트로그램 이미지를 **스캐닝하여 필터링** 거침
- **RMS(Root Mean Square)** 같은 이미지 변환 기법 활용
- 이를 통해 타임 시리즈로 변환

## 5. 시계열 분석의 중요성 강조

참석자 2가 "시간축을 빼고 주파수 특징만 보면 안 되냐"고 묻자, 교수님은 다음과 같이 설명:

- 원본 데이터 자체가 **10초 간격으로 FFT를 돌린 시간 연속 데이터**
- 데이터가 연속적으로 이어지므로 **타임 시리즈로 보는 것이 맞음**
- 시간에 따른 패턴이 중요한 이유:
    - 평소엔 일상적이다가 갑자기 진동이 발생할 수 있음
    - 주기가 점점 빨라지는 등 동작에 따른 변화가 나타남
    - 예: 모터에서 액셀을 밟을 때마다 발생하는 패턴 변화

## 6. 진행 방향

1. **우선 단순하게 시도**: 피크 주파수 + 레인지만으로 시계열 구성
2. **결과가 잘 나오면 → 대박**
3. **결과가 부족하면 → 특징을 하나씩 추가**
4. 구체적인 구현 방법은 **담당자(참석자 2 측)가 직접 찾아서 진행**
