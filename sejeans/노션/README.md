## 1. 이 대시보드가 하는 일

전기차는 내부 부품이 복잡해서 육안으로 이상 여부를 파악하기 어렵습니다.  
이 시스템은 차량 센서 데이터를 분석해 아래 두 가지 이상을 자동으로 탐지합니다.

| 감시 대상 | 탐지 내용 |
|---|---|
| **모터-감속기** | 전류 · 진동 이상, 결함 종류(단락 · 감자 · 감속기 이상 등) |
| **배터리** | 셀 전압 불균형, 배터리 건강도(SOH), 불량 셀 위치 |

이상이 감지되면 화면 색상이 바뀌고 하단 경보 로그에 기록이 남습니다.

## 2. 실행 방법

> **필요한 것:** Python 3.9 이상, Node.js 18 이상

### 터미널 1 — 백엔드(서버) 실행

```bash
cd dashboard/backend
pip install -r requirements.txt
python run.py
```

성공하면 터미널에 `Uvicorn running on http://0.0.0.0:8000` 메시지가 표시됩니다.

### 터미널 2 — 프론트엔드(화면) 실행

```bash
cd dashboard/frontend
npm install
npm run dev
```

성공하면 터미널에 `Local: http://localhost:5173` 메시지가 표시됩니다.

### 브라우저 접속

백엔드와 프론트엔드가 모두 실행된 상태에서 브라우저 주소창에 입력:

```
http://localhost:5173
```

## 4. 상단 헤더 조작법

화면 최상단에 항상 고정된 영역입니다.

### 차량 선택 (왼쪽)

드롭다운 메뉴에서 분석할 차량 모델을 선택합니다.

| 선택지 | 설명 |
|---|---|
| **IONIQ** | 아이오닉 계열 (96셀 배터리) |
| **KONA** | 코나 일렉트릭 (98셀 배터리) |
| **NIRO** | 니로 EV |

차량을 바꾸면 해당 차종의 샘플 데이터로 화면이 초기화됩니다.

### 전체 상태 표시등 (가운데)

전체 시스템의 현재 상태를 한눈에 보여줍니다.

- 초록 점 + **정상** → 모터·배터리 모두 이상 없음
- 노란 점 + **주의** → 한 곳 이상에서 주의 수준 감지
- 빨간 점(깜빡임) + **경고** → 즉각 조치가 필요한 이상 감지

### FPS / WebSocket 상태 (가운데)

| 표시 | 의미 |
|---|---|
| **FPS** | 데이터가 초당 몇 번 갱신되는지 (실시간 스트리밍 중에만 의미 있음) |
| **WebSocket 연결됨** | 실시간 데이터 스트리밍이 활성화된 상태 |
| **WebSocket 연결 끊김** | 스트리밍 비활성화 상태 |

### 조작 버튼 (오른쪽)

| 버튼 | 동작 |
|---|---|
| **데이터 요청** | 서버에서 샘플 데이터를 한 번 가져와 화면을 갱신합니다 |
| **데모 시작** | WebSocket을 연결해 데이터가 자동으로 계속 갱신됩니다 |
| **스트리밍 중지** | 실시간 갱신을 멈춥니다 (데모 시작 후 나타남) |

> **처음 사용한다면:** "데모 시작" 버튼을 누르면 데이터가 자동으로 계속 바뀌어 대시보드의 전체 기능을 볼 수 있습니다.

## 5. 모터-감속기 패널

화면 **왼쪽** 절반을 차지하는 패널입니다.

### 패널 헤더

- **MSE 수치**: 모터의 이상 점수입니다. 숫자가 클수록 정상 상태와 차이가 크다는 뜻입니다.
- 임계값(threshold)을 초과하면 자동으로 주의/경고 상태로 전환됩니다.

### 센서 게이지 (3개 막대)

모터에 부착된 3개 센서의 이상 기여도를 보여줍니다.

| 센서 이름 | 측정 대상 |
|---|---|
| **current_u** | U상 전류 — 모터에 흐르는 전기 |
| **vib_motor** | 모터 진동 |
| **vib_tm** | 변속기(감속기) 진동 |

막대가 길고 빨갈수록 해당 센서에서 이상이 강하게 감지된 것입니다.

### 스펙트로그램 뷰어

모터 진동을 시간-주파수 이미지로 변환한 것입니다.  
정상 상태는 패턴이 균일하고, 이상이 있으면 특정 주파수 대역에 밝은 줄무늬가 나타납니다.

- **결함 유형(Fault Type)** 표시:

| 표시 | 의미 |
|---|---|
| NORMAL | 정상 |
| ECC10 | 편심 결함 10% |
| ECC20 | 편심 결함 20% |
| DEMAG | 영구자석 감자 |
| REDUC | 감속기 이상 |

### 이상 점수 추이 그래프

시간에 따른 MSE 이상 점수 변화를 꺾은선 그래프로 보여줍니다.  
빨간 점선이 임계값이며, 이 선을 넘으면 경보가 발생합니다.

## 6. 배터리 패널

화면 **오른쪽** 절반을 차지하는 패널입니다.

### 패널 헤더

- **SOH 수치**: 배터리 건강도(State of Health)입니다. 100에 가까울수록 건강한 상태입니다.

### 건강도(SOH) 게이지

반원형 게이지로 배터리 건강도를 직관적으로 표시합니다.

| SOH 범위 | 상태 |
|---|---|
| 약 80 이상 | 정상 (초록) |
| 약 60~80 | 주의 (노랑) |
| 약 60 미만 | 경고 (빨강) |

### 셀 그리드

배터리를 구성하는 개별 셀(96개 또는 98개)을 격자로 표시합니다.  
- **색이 진한 셀** → 해당 셀의 전압이 비정상적으로 낮거나 불균형 상태
- 이를 통해 **어느 셀이 문제인지** 위치를 바로 파악할 수 있습니다.

### 분류 확률 바

AI 모델이 판단한 각 상태의 확률을 가로 막대로 보여줍니다.

| 색상 | 분류 |
|---|---|
| 초록 | NORMAL (정상) |
| 노랑 | CAUTION (주의) |
| 빨강 | DEFECT (불량) |

막대가 가장 긴 항목이 현재 시스템이 판단하는 상태입니다.

### 상세 수치

| 항목 | 설명 |
|---|---|
| **최소 셀 전압** | 전체 셀 중 가장 낮은 전압 (3.3V 미만이면 위험) |
| **전압 편차** | 셀 간 전압 차이 (클수록 불균형 심각) |
| **온도** | 배터리 온도 (해당 데이터가 있을 경우) |
| **셀 수** | 배터리 팩을 구성하는 셀 개수 |

## 7. 경보 로그

화면 **하단**에 고정된 영역으로, 이상이 감지될 때마다 자동으로 기록이 추가됩니다.

| 항목 | 설명 |
|---|---|
| **시각** | 이상이 감지된 시간 |
| **차량 ID** | 이상이 발생한 차량 식별 코드 (예: MOB-X001) |
| **등급** | 주의 / 경고 |
| **내용** | 이상 내용 요약 (모터 MSE 수치 또는 배터리 SOH 수치) |

최근 100건까지 보관되며, 새 경보가 위에 쌓입니다.

## 8. 상태 색상 의미

이 대시보드에서 사용하는 색상은 일관된 의미를 가집니다.

| 색상 | 상태 | 행동 지침 |
|---|---|---|
| **초록** | 정상 | 이상 없음 |
| **노랑** | 주의 | 지속 모니터링 권장 |
| **빨강 (깜빡임)** | 경고 | 즉각 점검 필요 |

## 9. 자주 묻는 질문

**Q. 백엔드 없이 프론트엔드만 실행해도 되나요?**  
A. 됩니다. 백엔드 연결에 실패하면 자동으로 목업(Mockup) 데이터를 사용해 화면을 표시합니다. 상단에 "백엔드 연결 실패 — 목 데이터 사용 중" 메시지가 표시됩니다.

**Q. "데이터 요청"과 "데모 시작"의 차이는 무엇인가요?**  
A. "데이터 요청"은 버튼을 누를 때 한 번만 데이터를 가져옵니다. "데모 시작"은 WebSocket을 연결해 데이터가 자동으로 계속 갱신됩니다.

**Q. 차량을 바꾸면 어떻게 되나요?**  
A. 해당 차종의 샘플 데이터로 초기화되고, 이상 점수 추이 그래프도 리셋됩니다.

**Q. API 문서는 어디서 볼 수 있나요?**  
A. 백엔드 실행 후 브라우저에서 `http://localhost:8000/docs` 에 접속하면 전체 API 목록을 확인할 수 있습니다.

**Q. 실제 차량 데이터를 올릴 수 있나요?**  
A. 가능합니다. `http://localhost:8000/docs` 에서 `/api/inference/motor` (PNG 파일) 또는 `/api/inference/battery` (NPY 파일)로 직접 업로드할 수 있습니다.
