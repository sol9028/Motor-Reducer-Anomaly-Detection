# 저번 시간 피드백

**전체 이미지를 다 쓸 필요 없이, 핵심 특징만 추출하자**

추출할 특징:

- **시간축**: 인덱스로 사용
- **피크 주파수(Peak Frequency)**: 시간에 따라 흔들리는 중심 주파수 값
- **밴드 레인지(Band Range)**: 임계치를 넘는 영역의 시작점과 끝점 (Start ~ End)

→ 결과적으로 **3개 컬럼** 정도의 시계열 데이터로 압축 가능 (레인지를 통으로 묶으면 더 축소 가능)

- 에너지가 상위 10%(90th percentile 임계치 이상)인 픽셀만 "활성 주파수 대역"으로 보고, 아래 4개 피처를 CSV로 저장
    1. 원본 STFT 이미지를 그대로 표시
    2. 컬러 편차 없이 순수 에너지 강도만을 보기 위한 전처리
    3. 각 시간 인덱스(x)에서 에너지가 **가장 큰 단일 주파수 bin**의 위치를 추적한 그래프
    4. 임계치(상위 10%) 이상인 활성 주파수 bin들의 **최솟값(band_start)~최댓값(band_end) 범위**를 면적으로 표시
    5. 각 시간 컬럼의 전체 에너지 크기를 RMS(Root Mean Square)로 계산한 값

# 피드백

- 이미지를 쓰되 이미지 자체를 줄이는 방법, 특징만 더 뽑아낸다든지
- 

### 1. 데이터 추출 결과에 대한 피드백

- 혼돈스러운 데이터에 대한 관점 변화: 추출된 데이터가 복잡하고 '혼돈의 도가니'처럼 보일지라도, 원본 이미지 자체도 복잡한 상태이므로 지레 겁먹을 필요가 없습니다.
- 딥러닝의 특징 추출 능력 신뢰: CNN 계열의 모델은 넓은 범위의 이미지에서 점진적으로 피처(Feature)를 좁혀가며 스스로 특징을 잡아냅니다. 인간의 눈에 복잡해 보여도 모델은 색상 비중이나 명암 등에서 유의미한 정보를 찾아낼 수 있습니다.
- 패턴의 존재 확인: 데이터를 확대하거나 자세히 살펴보면 특정 구간에 데이터가 몰리거나 비어있는 등, 완전히 패턴이 없는 것은 아닙니다. 특히 고장 영역과 정상 영역, 가속 구간 등의 조짐이 이미지상에 나타나고 있습니다.

### 2. 분석 모델 및 실험 방향

- 선(先) 실행 후(後) 판단: 현재 정보만으로는 모델이 어떤 특징을 뽑아낼지 확신할 수 없으므로, 일단 돌려보고 결과를 확인하는 것이 우선입니다.
- **성능 지표에 따른 대응**:
    - 적중률이 70~80% 이상 나온다면 가능성이 있는 것으로 판단하고 고도화 전략을 세웁니다.
    - 만약 기존의 높은 적중률(98%)에 비해 현저히 낮은 결과가 나온다면, 해당 추출 데이터가 원본을 대변하지 못하는 것이므로 다른 데이터를 검토해야 합니다.
- 데이터 가공 전략: 실험 결과에 따라 유효한 정보는 추가하고, 불필요한 정보는 제외하며 피처를 조정해 나가는 과정이 필요합니다.

### 3. 모델 최적화 및 효율성 검토

- 데이터 사이즈 및 해상도 조절: 현재 1024x1024 수준인 이미지 해상도를 256x256 등으로 낮추었을 때 성과 차이가 없다면, 모델 경량화를 위해 사이즈를 줄이는 것이 효율적입니다.
- 기존 연구 사례 참고: 기존 연구자들이 고해상도를 유지했다면 해상도를 낮췄을 때 정확도(Accuracy)가 떨어졌을 가능성이 높으므로 이를 유의해야 합니다.

### 4. 향후 계획 및 기타 사항

- 연구 범위 집중: 프로토타입 단계에서는 여러 항목을 다루기보다 모터(Motor) 부분에 집중하여 깊이 있게 분석하는 방향으로 진행합니다
- 결과물 가치: 데이터를 잘 추출하고 정리한다면 충분히 논문으로서의 가치가 있을 것으로 기대됩니다.
