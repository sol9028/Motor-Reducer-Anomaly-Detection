## 근거를 선택한 기준

성능과 오류 수는 평가 JSON을 우선했습니다. 실험 설정은 학습·추출·벤치마크 코드를 대조했고, 변화 과정은 발표자료·프로젝트결과보고서·실험 정리에서 확인했습니다. 메모가 결과 JSON과 다르면 JSON 값을 사용했습니다. 이번 작업에서 모델을 재학습하거나 새 성능 실험을 수행하지 않았습니다.

## 수치와 표현을 수정한 항목

1. **초기 프롬프트의 0.826~0.874와 최종 0.9729를 구분.** 추출기·그룹 정의·표본 구성이 다릅니다. 최종 87채널과 51채널은 차종별 청크 및 그룹 수가 일치합니다.
2. **12채널의 비교 제한.** 저장 베이스라인은 차종당 20,000청크, 최종은 14,898/14,966/16,796청크입니다. 12→87 전체 변화는 한 번에 한 요인만 바꾼 효과량이 아닙니다.
3. **그룹 정의 비교의 청크 수도 다름.** 15채널 `group_key`와 `timestamp` 점수 차이를 순수한 누수 크기로 단정하지 않았습니다.
4. **704→433은 DEMAG→NORMAL 한 방향.** 감소율 38.4943%. 양방향은 1,462→1,060으로 27.4966% 감소합니다.
5. **51채널 차수축 단독 0.9562.** 노션 표 일부의 0.9635와 다른 원본 JSON·학습 리포트 값을 사용했습니다.
6. **15채널 평균 0.8814.** 노션의 0.870 대신 JSON을 사용했습니다.
7. **87채널 최종 평균 0.9729329.** 차종별 0.9861498/0.9682026/0.9644462의 산술 평균입니다. 모든 청크를 합친 단일 점수가 아닙니다.
8. **실제 특징 수 9,996/4,956/2,436/1,176.** 요청값 10,000/5,000/2,500/1,250과 구분했습니다. 84개 기본 커널 구조에 따른 출력 특징 수입니다.
9. **4,956 구성이 2,436에 모든 축에서 지배된다고 쓰지 않음.** 평균 Macro-F1이 약 0.9707과 0.9691로 다릅니다.
10. **변환 단계 비율 약 99.35%.** `452.08/455.04`로 계산했습니다. 메모의 99.7%를 사용하지 않았습니다. 단계별 중앙값은 전체 중앙값과 단순 합산되지 않을 수 있습니다.
11. **모델 0.69MB와 RSS 193.3MB를 구분.** 전자는 학습 리포트의 차종별 직렬화 크기, 후자는 네 레지스트리를 적재한 프로세스의 상주 메모리이며 최대값이 아닙니다.
12. **온도 37.4~43.8°C.** 동봉 JSON의 측정 전후값을 사용했습니다. 메모의 시작 33.6°C·40분 연속 무스로틀 주장은 별도 로그가 없어 사용하지 않았습니다.
13. **스레드 요청과 CPU 점유 구분.** 1/4스레드 요청에서 지연 변화가 작은 것을 보고합니다. 실제 한 코어 전용 사용이나 병렬화 불가능은 주장하지 않았습니다.
14. **p99의 한계.** 단건 30회, 배치 8은 10회, 배치 32는 5회입니다. 짧은 표본의 백분위수이며 최악 실행시간 보장이 아닙니다.
15. **데이터 1.15TB→107GB.** `7조_최종발표.pdf` 3·5쪽에 표기되어 있으나 파일 단위 집계 원본을 확보하지 못했고 600GB와 집계 범위 차이가 있어 핵심 정량 결과에서 제외했습니다. CAN의 5.28TB→110MB와도 다른 대상입니다.
16. **기존 연구의 mIoU 0.99라는 단일 표현을 사용하지 않음.** 박병준·한동석(2024)은 분류 정확도 99.63%와 클래스별 값 99.63/93.36/91.05/95.73/98.24%를 제시합니다. 전 클래스 평균 mIoU 99%라고 바꾸지 않았습니다.
17. **개별 센서 평균을 late fusion 점수로 단정하지 않음.** 초기 보고서 표의 `late(센서별 평균)`은 확률 합산 모델의 실제 점수와 구분했습니다.
18. **최종 분류기는 LogisticRegression.** 프롬프트의 RidgeClassifierCV는 후보로만 남겼습니다. 최종 Ridge 비교 결과를 생성하지 않았습니다.

## 논문에 표시한 중요한 제한

- `train_slot()`은 `build_features(X)`를 전체 입력에서 실행한 다음 그룹 CV를 수행합니다. `build_features()`의 채널 통계와 `mr.fit(Xn)`에 검증 입력도 포함됩니다. 분류기 앞 StandardScaler만 폴드별입니다. 그룹이 겹치지 않아도 완전한 폴드 내부 평가가 아닙니다.
- `row_detrend()`의 시간 중앙값과 전체 임계값은 병합 구간 전체를 사용합니다. 온라인 사용 시 미래 입력을 참조하지 않도록 설계해야 합니다.
- LUT 값은 색표의 정규화 스칼라이며 신호 전력·물리 에너지를 완전 복원한 값이 아닙니다. 9개 샘플에서 jet이 최적인 파일은 7개이고 일부 평탄 영역에도 큰 잔차가 있습니다.
- 차수축은 Hz 기준 보정이 없는 bin/rpm 재표본화입니다. 기준값보다 낮은 rpm에서는 원본 저주파 구간이 출력 전체로 늘어나므로 원본 전 주파수 정보를 보존하는 변환으로 설명하지 않았습니다.
- Pi 지연은 표준화·MiniROCKET·분류를 포함합니다. STFT·LUT·특징 추출·센서 수집·통신은 제외됩니다.
- Pi의 455ms는 초기 PC 목표 100ms를 충족하지 않습니다. 10초 입력 주기보다 계산 구간이 짧다는 별개의 판단을 사용했습니다.
- JSON에 측정된 슬롯은 IONIQ입니다. 다른 두 차종의 Pi 지연 실측으로 확대하지 않았습니다.
- `bench_latency.py`는 실데이터 파일이 없으면 난수를 사용합니다. JSON만으로 실제 입력 사용 여부를 확인할 수 없습니다.
- 온도 추가 기각은 인버터 온도 실험에 한정합니다. 다른 CAN 온도나 조건부 온도 정보까지 무용하다고 설명하지 않았습니다.

## 추가 확인한 외부 원문

- [AI-Hub 자율주행 고장진단 데이터](https://aihub.or.kr/aihubdata/data/view.do?aihubDataSe=data&currMenu=115&dataSetSn=71347&topMenu=100): 실제 환경에서 자체 수집, 구축연도 및 클래스 정의 확인.
- [MiniROCKET 원문](https://arxiv.org/abs/2012.08791) 및 [저자 소속 대학 서지](https://research.monash.edu/en/publications/minirocket-a-very-fast-almost-deterministic-transform-for-time-se/): 2021 KDD, 248–257, DOI `10.1145/3447548.3467231` 확인.
- [sktime API](https://www.sktime.net/docs/api-reference/sktimetransformationsrocketminirocketmultivariate/): 84개 기본 커널과 요청값의 반올림 규칙 확인. 온라인 문서 버전과 실험 당시 버전을 동일시하지 않음.
- [scikit-learn 데이터 누수 안내](https://scikit-learn.org/stable/common_pitfalls.html): 검증 입력을 적합에 사용하지 않는 평가 원칙 확인.
- [IEA 2025 보고서](https://www.iea.org/reports/global-ev-outlook-2025/trends-in-electric-car-markets-2): 2024년 전기 승용차 판매 1,700만 대 초과, BEV/PHEV 포함. 최신 2026 통계로 소개하지 않고 연도 명시.
