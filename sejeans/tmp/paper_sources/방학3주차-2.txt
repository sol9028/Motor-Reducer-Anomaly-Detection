2. 공통 학습 방법 (모든 실험 동일)
모터_학습_v3.py — 3차 발표의 early fusion 방식 유지:
세션의 3센서(Current_U, Vib_Motor, Vib_TM)를 채널로 스택 → chunk 2000행
클래스당 캡 4,000청크 (세션 균등 추출) → 채널 표준화 → MiniRocketMultivariate(10,000커널) 1회 변환
StratifiedGroupKFold 3-fold (폴드마다 LogisticRegression만 재학습) → 전체 재학습 저장
차종당 모델 1개 (IONIQ / KONA / NIRO), 5클래스 (DEMAG, ECC10, ECC20, NORMAL, REDUC)
CV 그룹 = timestamp: 같은 주행(timestamp)의 zsplit들이 train/test로 갈리는 누수 차단
진단 내장: rpm단독 F1(지름길 검사), 클래스당 세션 수, DEMAG-NORMAL 혼동

4. 비교쌍 해석 (통제 변인별)
① rpm 순수 효과 (1단계 vs A1 — 둘 다 timestamp, rpm만 차이)
NIRO만 뚜렷한 이득(+0.029, DEMAG recall +3.6%p), IONIQ 소폭 하락, KONA는 DEMAG recall −4.3%p.
→ 차종별 엇갈림. rpm단독 F1은 0.208~0.238로 지름길(컨닝)은 아님 — 보조 정보로 작동.
② zsplit 누수 크기 (2단계 vs A1 — 둘 다 15ch, CV 단위만 차이)

④ 확장특징 12개 (A1 vs A4 — 확장특징만 추가, 청크 수 동일해 정확한 비교)

→ 채택 확정 (사용자 판정). "DEMAG는 에너지 재분배 고장 → 대역비율로 재분배를 직접 표현"이라는 설계 의도가 검증됨.

→ band_ratio_7(최고주파 대역, float16 언더플로우 5.91%)은 기여가 없고 KONA에서는 오히려 해로움.
→ 최종 구성을 51ch로 갈지 48ch로 갈지 결정 필요 (아래 §6).
