# 클로드 디자인 프롬프트 — EV 이상탐지 실시간 모니터링 대시보드

아래 전문을 클로드 디자인에 그대로 붙여넣으면 됩니다.

---

전기차(EV) 구동계 이상탐지 시스템의 **실시간 모니터링 대시보드** 화면을 디자인해줘.
데스크톱 웹 기준 1440×900, 단일 화면에 스크롤 없이 들어가는 레이아웃.

## 맥락

차량에 붙은 센서 신호를 엣지 디바이스에서 실시간 추론해서, 모터-감속기와 배터리의
이상 상태를 감시하는 시스템이야. 정비 담당자가 상시 띄워놓고 흘끗 보는 화면이라
**"지금 괜찮은가"가 1초 안에 읽혀야 해.**

이전 버전은 센서(Current_U / Vib_Motor / Vib_TM)별로 게이지가 3개씩 따로 있었는데,
지금은 **센서 신호를 융합한 통합 모델 하나**라서 게이지도 하나로 합쳐야 해.
센서별 분리 표시는 더 이상 필요 없어.

## 화면에 들어갈 것 (우선순위 순)

### 1순위 — 화면 상단, 가장 크게

**통합 건강도 점수 + 게이지**
- 0~100 정수 점수 하나. **낮을수록 양호** (Anomaly Score 기반)
- 반원형 또는 원형 게이지, 구간별 색상:
  - 0~30 정상 (녹색)
  - 30~70 주의 (황색)
  - 70~100 위험 (적색)
- 점수 숫자는 아주 크게. 그 아래 상태 텍스트("정상" / "주의" / "위험")
- 게이지 옆에 현재 판정 클래스명과 마지막 갱신 시각

### 2순위 — 중단 좌우 분할

**(좌) 점수 시계열 라인 차트**
- x축은 스트리밍 청크 순서(시간), y축 0~100
- 30/70 임계선을 점선으로 깔아둠
- 최근 구간만 슬라이딩 윈도우로 보여주고, 이상 발생 지점은 마커로 강조

**(우) 클래스별 확률 막대 차트**
- 모터-감속기 5클래스: NORMAL / ECC10 / ECC20 / DEMAG / REDUC
- 가로 막대 추천 (클래스명이 길어서). 확률 높은 순 정렬, 최상위 막대만 강조색
- 각 막대에 확률값 라벨
- 배터리 3클래스(NORMAL / 셀 전압 이상 / 셀 편차 이상)도 탭 또는 토글로 전환

### 3순위 — 하단

**이상 탐지 로그 테이블**
- 컬럼: 시각 / 차량(IONIQ·KONA·NIRO) / 판정 클래스 / 점수 / 신뢰도
- 최신순 누적, 심각도에 따라 행 좌측에 색상 바
- 5~6행 정도만 보이고 스크롤

### 사이드바 또는 최하단 — 작게 (개발자/발표용)

이 두 개는 **실사용자에겐 필요 없고 졸업프로젝트 발표 때 보여주는 용도**야.
평소엔 눈에 안 띄게, 접기(collapse) 가능한 사이드바 하단이나 화면 맨 아래
작은 섹션으로 밀어줘. 메인 영역을 침범하면 안 돼.

**추론 속도**
- 청크당 추론 지연시간 p50 / p95 (ms), 처리량, 실행 환경 표기
- 실측값 예시: Raspberry Pi 4 (1 thread) 기준 청크당 p50 227ms

**정확도 — 혼동행렬**
- 5×5 히트맵. 축 라벨은 5개 클래스, 셀에 개수 표기
- 옆에 Accuracy / Macro-F1 요약 수치
- 실측값 예시: IONIQ Acc 0.986 / Macro-F1 0.986, KONA 0.967, NIRO 0.964

## 디자인 방향

- **톤**: 산업용 모니터링 계기판. 차분하고 신뢰감 있게. 장식 최소화
- **테마**: 다크 테마 우선 (상시 띄워두는 관제 화면이라 눈이 덜 피로함).
  라이트 테마도 함께 제안해주면 좋고
- **색상**: 상태색(녹/황/적)만 채도 높게 쓰고, 나머지 UI는 무채색 계열로 눌러줘.
  상태색이 유일한 신호가 되도록. 색맹 대응으로 색 외에 아이콘/텍스트도 같이
- **타이포**: 숫자 가독성 우선. 점수·지연시간 같은 수치는 tabular numerals
- **밀도**: 정보 밀도는 높되 카드 사이 여백으로 그룹을 구분. 카드마다 얇은 보더 + 약한 그림자
- 상단에 얇은 헤더: 시스템명, 차량 선택 드롭다운, 스트리밍 시작/정지 버튼, 연결 상태 표시등

## 요청 산출물

1. 메인 대시보드 전체 화면 (정상 상태)
2. 같은 화면의 이상 감지 상태 (점수 높고 경보 활성화된 버전)
3. 개발자용 섹션(추론속도 + 혼동행렬)이 펼쳐진 상태
